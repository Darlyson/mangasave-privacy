Política de Privacidade — MangaSave

Última atualização: Outubro de 2026

🇺🇸 Read in English below
Resumo Transparente: O MangaSave funciona de forma 100% local no seu navegador. Nós não coletamos, não armazenamos em servidores próprios, não rastreamos e não vendemos nenhum dado pessoal, histórico de navegação ou lista de favoritos.

1. Armazenamento de Dados

Toda a sua biblioteca de mangás, capítulos salvos, preferências visuais e configurações ficam armazenados exclusivamente no seu próprio dispositivo por meio da API oficial do navegador (chrome.storage.local). Nenhum dado da sua biblioteca é transmitido para servidores do desenvolvedor.

2. Uso das Permissões da Extensão

O MangaSave solicita apenas as permissões estritamente necessárias para o seu funcionamento:

  • storage e unlimitedStorage: Usadas para salvar localmente a sua biblioteca de obras, capas, capítulos e configurações sem risco de perda por limite de espaço.
  • activeTab, tabs, scripting e offscreen: Usadas apenas quando você aciona o botão de salvar o capítulo da página atual, pesquisar obras ou verificar se os links salvos na sua biblioteca continuam ativos (Verificador de Saúde e Centro de Resgate).
  • bookmarks: Usada exclusivamente quando você escolhe importar pastas de favoritos já existentes no seu navegador para dentro da biblioteca do MangaSave. Seus favoritos originais nunca são alterados ou apagados.
  • downloads: Usada para permitir que você exporte um arquivo de backup (.json) da sua biblioteca para o seu computador.
  • alarms e notifications: Usadas para checar periodicamente atualizações de status/capas de obras em lançamento (quando ativado por você nos Ajustes) e avisar quando uma importação ou verificação termina.

3. Serviços de Terceiros e APIs Públicas

Para enriquecer sua biblioteca com capas oficiais, sinopses, tags e autores, a extensão faz consultas diretas do seu navegador para APIs públicas de catalogação:

  • MangaDex API (api.mangadex.org / uploads.mangadex.org)
  • AniList GraphQL API (graphql.anilist.co)
  • Google Translate API (translate.googleapis.com) — usada apenas como fallback para traduzir termos de busca quando necessário.

4. Compartilhamento e Venda de Dados

O MangaSave não coleta, não compartilha, não transfere e não vende dados de usuários a terceiros, anunciantes ou corretores de dados. O uso de informações recebidas das APIs do Google Chrome respeita integralmente a Chrome Web Store User Data Policy, incluindo os requisitos de Uso Limitado (Limited Use).

Privacy Policy — MangaSave

Last updated: October 2026

Summary: MangaSave operates 100% locally in your browser. We do not collect, store on external servers, track, or sell any personal data, browsing history, or bookmarks.

1. Data Storage

Your entire manga library, saved chapters, visual preferences, and settings are stored exclusively on your own device using the browser's native storage API (chrome.storage.local). No library data is ever sent to developer-owned servers.

2. Extension Permissions Justification

  • storage & unlimitedStorage: Required to store the user's manga library, metadata, and preferences locally on the device.
  • activeTab, tabs, scripting & offscreen: Used only upon user request to capture the current chapter from the active tab, search for titles, or check the health status of saved chapter links.
  • bookmarks: Used solely when the user explicitly imports a browser bookmark folder into their MangaSave library (read-only).
  • downloads: Used to export a local JSON backup file of the user's library when requested.
  • alarms & notifications: Used for optional periodic metadata refresh of ongoing series and to notify the user when batch imports or link health checks complete.

3. Third-Party Public APIs

To fetch official cover art, synopses, genres, and author metadata, the extension queries public catalog APIs directly from the user's browser: MangaDex API (api.mangadex.org), AniList API (graphql.anilist.co), and Google Translate endpoint for title fallback queries.

4. Limited Use Disclosure

MangaSave does not collect, sell, or transfer user data to third parties. The use of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.
